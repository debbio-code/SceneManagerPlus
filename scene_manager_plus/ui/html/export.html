⚠ Version Control X — l'export archivia in Superate/ e rimpiazza solo il tuo set: le copie del set vecchio nelle cartelle dei colleghi restano al loro posto. Se hai tolto o rinominato scene, lì sopravvivono immagini che sembrano valide (nessuna versione più recente le "batte") e la bonifica le riporterebbe sul master. Occhio anche alla numerazione: togliere una scena fa slittare i numeri di quelle dopo, il residuo orfano è l'ultimo numero. Dopo l'export: in VCX controlla le immagini con data fuori dal set e cestina i residui.
